# Solar Pro Console

IMPORTANT DESIGN PRINCIPLE:

Solar Pro must never look like a generic AI-generated, "vibecoded" SaaS application.

Avoid common AI-generated web design patterns and decorative UI trends.

DO NOT automatically use:

- Harsh or multi-color gradients

- Rainbow color schemes

- Glassmorphism

- Excessive translucent cards

- Floating decorative blobs or radial orbs

- Random decorative Lucide icons

- Icons beside every heading or navigation item

- Excessive rounded rectangles

- Pill-shaped UI elements unless functionally appropriate

- Repeated three-feature-card layouts

- Generic bento grids used purely for decoration

- Fake testimonials

- Fake customer logos

- Fake product metrics

- Oversized startup-style typography

- Excessive em dashes

- Generic phrases such as "revolutionize", "supercharge", "seamlessly", or "unlock the power of"

Every visual element must have a clear functional or brand purpose.

The product must feel deliberately designed by an experienced product designer and engineer.

Prioritize:

- Information hierarchy

- Usability

- Realistic workflows

- Real data models

- Clear navigation

- Semantic use of color

- Consistent spacing

- Strong typography

- Professional density

- Accessible contrast

Do not make every page card-based.

Use different layouts where appropriate:

- Tables

- Lists

- Charts

- Detail pages

- Split layouts

- Forms

- Timeline views

- Operational dashboards

Do not decorate empty space unnecessarily.

Whitespace is intentional.

The application should feel like professional energy infrastructure software, not a startup landing page generated from a prompt.

Before adding any visual component, consider whether it improves:

1. Usability

2. Comprehension

3. Navigation

4. Data interpretation

5. Brand recognition

If it does not improve one of these areas, do not add it.

Avoid inventing fake data purely to make screens look complete.

When sample data is required, make it realistic, internally consistent, and clearly structured around the actual Solar Pro data model.
